GitHub Focus PR — Settings

When a link opens a new tab for a PR you already have open, close the new tab and focus the existing one instead. Cmd/Ctrl-clicking links inside the PR's own tab still opens duplicates on purpose.

On PR pages, automatically click "Load more…" until the whole conversation is visible, then scroll to the comment the link pointed at. Prevents the jumping around caused by GitHub collapsing long timelines after a reload.

How often to ask the GitHub API whether your open PRs have new comments, review comments, or commits.

Needed for private repositories and for a higher API rate limit (5,000/hr vs 60/hr). Create a fine-grained token with read-only Pull requests permission at github.com/settings/tokens. Stored only in this browser's extension storage.
